# meta-mchp-mpu-apps

## Description

This layer provides application recipes and image configurations for Microchip MPU boards for use with OpenEmbedded and/or Yocto Project.

## Layer Dependencies

This layer depends on:

```text
URI: git://github.com/linux4microchip/meta-mchp.git
layers: meta-mchp-mpu-bsp

URI: git://git.openembedded.org/meta-openembedded
layers: meta-oe
```

## Supported Yocto Releases

This layer is compatible with the following Yocto Project releases:

- scarthgap
