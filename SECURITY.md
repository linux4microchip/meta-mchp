# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by opening a new issue at:

**<https://github.com/linux4microchip/meta-mchp/issues/new>**

Please include as much detail as possible to help us understand and address the issue quickly.

## Private Disclosure

For sensitive vulnerabilities involving unreleased code or issues that should not be disclosed publicly, please contact the maintainers directly:

- Valentina Fernandez Alanis <valentina.fernandezalanis@microchip.com>
- Nicolas Ferre <nicolas.ferre@microchip.com>
